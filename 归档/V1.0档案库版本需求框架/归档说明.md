1. **不得基于本目录任何文档启动开发**——它们描述的是已被替换的架构。
2. 唯一 Schema / 业务规则真相源 = **《需求规格/数据库设计文档-助理版》**（自包含、零外部引用）。
3. 若在本目录发现与助理版冲突的表述，**一律以助理版为准**。
4. 术语已换代，读旧文档时注意映射：
   - 旧「跟单记录」→ 新「action_event 事件流」
   - 旧「阶段/紧迫/价值 手写标签」→ 新「系统推导（只读）+ 销售确认」
