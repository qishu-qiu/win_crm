# AI 执行清单（★ 每轮必读 · 唯一「行为规则」落点）

> **是什么**：每轮必读的检查表，只写「触发时机 → 动作」（写不出「时机 ＋ 动作」的只配待在案例库）；证据与"为什么"见《AI协作铁律与踩坑复盘》（案例库，按需查）。
> **维护**：新坑进案例库；能变成可判定动作的同批在此加一行。

## 一、跑命令

1–4. 命令输出**只读一路**（`2>$null`，不写 `2>&1`）｜ git 加 `-c core.quotepath=false` ｜ 取尾用 `Select-Object -Last N` ｜ diff 只用 `--stat` / `--numstat` / `--short`。
5. 单测**只用 `npm test`**（`npx jest` 会加载失败）。
6. **`gen:types` 前先起后端**；改 `schema.prisma` 后必跑 `prisma:generate`。
7. 重启服务**按 `dist/main` / `dist/worker` 特征杀**，并验"只有新代码才有的行为"。

## 二、动手前

8. **无当轮明文执行令 → 先发「我准备做：___，回『执行』我才动」**，未回**原地停住**；新建文档 / 目录也算跨界。
9. **短回复（继续 / 好的）只对最近一个待办有效**，绝不外推；多议题逐条确认。
10. 联动＝执行令子项：改口径 / 接口 / 表结构 → **同批**改上游文档 ＋ 指针 ＋ 生成物；**例外＝改业务口径本身**。

## 三、改文件前后

11. **改前 grep 全部引用**（防断指针）；**整篇重写文件前先看该文件最新版**。
12. 中文批量替换**只用字面 `.Replace()`**（禁正则）；先单文件试跑 ＋ `--numstat` 确认只变 1~3 行，改完跑三校验。
13. 引用写「《文档名》§X」，不写版本号。

## 四、写完码

14. 后端**三绿** `tsc / lint / test`；前端**双绿** `lint / build`。
15. 涉模块解析 / 打包 / 依赖加载 → **必须真起一次进程**（三绿 ≠ 能跑）。
16. **单测全绿 ≠ 真链路对**：桩件按真实形状造，改完**真库跑一遍出参**。
17. 改 DTO **必 `gen:types`**，并 grep `Record<string, never>`（应为 0）。

## 五、提交前

18–20. **`git status --short` 逐文件认领**，只显式 add 本轮动过的路径 ｜ **禁 `git add -A` / `git add .` / `git commit -a`** ｜ 别人的半成品不碰不提交，原地报告。

## 六、待拍板

**建议即负责**：给方案 / 选型建议（含待拍板项），**必附长期价值评估**——多方案先排长期价值序、明确标出哪条是"图省事的技术债"（后期返工成本），不默认推最快的那个（→ 案例库坑 39 / 通例）。
21. **四要素缺一不可**：**谁**（哪份文档 / 模块，说人话）／**干什么的**（现在管什么）／**建议**（怎么做 ＋ 为什么 ＋ **长期价值对比**）／**影响范围**（不做怎样、做了动到什么）。
22–23. 当轮待拍项**一次列全、编号**，每条首句说清"拍哪件事" ｜ **判据：他不看代码、不翻文档就能答复**，做不到＝重写。

## 七、收尾

24–25. **本轮 ≥2 次提交 或 全文读过 ≥2 个大文件 → 主动提示换窗**（先更新交接说明 ＋ 提交 ＋ 树干净）｜ 交接说明 / 欠账台账保持最新。

## 八、喊停

26. 一听"**等一下 / 我没说 / 谁确认的**" → **立即回退到等待指令态，承认擅自推进，不辩解往前蹭**。
