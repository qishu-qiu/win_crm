# AI 执行清单（★ 每轮必读 · 唯一「行为规则」落点）

> **是什么**：AI 动手时的**检查表**，**只写「什么时候 → 做什么」**。
> **为什么单列**：原《AI协作铁律与踩坑复盘》21 KB 作为"每轮重放层"太长 —— 规则被读了，**动作发生时却想不起来**。故拆两层：
> · **本文件（≤3 KB）＝每轮必读**，只放"会救命的动作"；
> · 《AI协作铁律与踩坑复盘》**降为案例库（按需查）**，放完整证据与新坑归档。
> **维护**：新坑写进案例库；**只要能变成一条可判定动作，同批在本文件加一行**。
> **判据**：写不出「触发时机 ＋ 动作」的，只配待在案例库。

## 一、跑命令时

1. **只读一路输出**：`npm test 2>$null | Select-Object -Last N` —— **不写 `2>&1`**（PowerShell 把 stderr 包成 ErrorRecord，stdout/stderr 各回显一遍＝白读一倍）。
2. **git 加 `-c core.quotepath=false`**（如 `git -c core.quotepath=false status --short`）—— 否则中文路径变八进制转义，体积 ×3。
3. **取尾用 `Select-Object -Last N`**（本机是 PowerShell，不是 bash）。
4. **永不跑全量 diff**：只用 `--stat` / `--numstat` / `--short`。
5. **单测只用 `npm test`**（项目脚本带环境变量）；`npx jest` 会加载失败。
6. **`gen:types` 前先起后端**；改 `schema.prisma` 后必跑 `prisma:generate`。
7. **重启服务按 `dist/main` / `dist/worker` 特征杀**，并**验证"只有新代码才有的行为"**（不看端口 200）。

## 二、写文件 / 装依赖 / 跑有副作用的命令前

8. **没有当轮明文执行令 → 先发「我准备做：___，回『执行』我才动」**，未回**原地停住**。**新建文档 / 新建目录也算跨界**。
9. **短回复（继续 / 好的 / 采纳）只对最近一个待办有效**，绝不外推；多议题逐条确认。
10. **联动是执行令的子项，不必另问**：改了口径 / 接口 / 表结构 → **同批**改上游文档 ＋ 版本指针 ＋ 生成物。
    **唯一例外**：**新增或修改业务口径本身** —— 必须单独拿令。

## 三、改文件前后

11. **改前 grep 全部引用**（删 / 改一节会断掉别处的指针）。
12. **中文批量替换只用字面 `.Replace()`**（禁正则）；先单文件试跑 ＋ `git diff --numstat` 确认只变 1~3 行；改完跑三校验。
13. **引用一律写「《文档名》§X」，不写版本号**。

## 四、写完码

14. **后端三绿** `tsc / lint / test`；**前端双绿** `lint / build`。
15. **凡涉模块解析 / 打包 / 依赖加载，必须真起一次进程**（三绿 ≠ 能跑）。
16. **单测全绿 ≠ 真链路对**：桩件按**真实形状、真实阶段**造；改完**真库跑一遍出参**。
17. **改 DTO 必 `gen:types`**，并 grep `Record<string, never>`（应为 0）。

## 五、提交前

18. **`git status --short` 逐文件认领**，只显式 add 本轮自己动过的路径。
19. **禁用 `git add -A` / `git add .` / `git commit -a`**。
20. 工作树里有**别人改到一半的文件** → **不碰不提交**，原地报告等指令。

## 六、需要七叔拍板时

21. **四要素缺一不可**：**谁**（哪份文档 / 哪个模块的事，说人话）／**干什么的**（它现在实际管什么）／**建议**（怎么做 ＋ 为什么）／**影响范围**（不做会怎样、做了动到什么）。
22. **当轮所有待拍项一次列全、编号**，每条第一句就说清"要你拍的是哪件事"。
23. **判据**：他**不看代码、不翻文档**就能答复；做不到＝没写清，重写。

## 七、完成一批改动后（★ 最贵的一条）

24. **提交后自检换窗**：**本轮累计 ≥2 次提交，或全文读过 ≥2 个大文件 → 主动提示换窗**（先更新交接说明 ＋ 提交 ＋ 保证工作树干净）。
    理由：每轮都要重放**全部历史 ＋ 常驻规则**，成本随轮数**平方增长** —— 拖长窗口是本项目最大的浪费。
25. **交接说明 ＋ 欠账台账保持在最新**（换窗成本取决于它们准不准）。

## 八、七叔喊停时

26. 一听"**等一下 / 我没说 / 谁确认的**" → **立即回退到等待指令态，承认擅自推进，不辩解往前蹭**。
