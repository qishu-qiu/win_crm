### 判据 3 · 故意跨域 import 被 lint 拦下

> `src/modules/` **尚未创建**（M1 才建），故域级规则暂无文件命中 —— 改用「**`kernel` 反引 `modules`**」这条必然命中的规则（架构 §5.4 首行 ＋ M0-44b）。

**命令**
```powershell
# ① 造越界文件
Set-Content src\kernel\__smoke_probe.ts "import { Probe } from '../modules/company/company.service';`nexport const _probe = Probe;"
# ② 跑 lint（预期报错）
npm run lint
# ③ 立即回滚
Remove-Item src\kernel\__smoke_probe.ts
# ④ 复验
npm run lint
```

**实测**
```
  1:1  error  '../modules/company/company.service' import is restricted from being used by a pattern.
              内核零业务依赖被拦（架构 §5.4）：`kernel/**` 不得 import `modules/*`，业务规矩不准下沉进内核。
              no-restricted-imports

lint exit=1        ← 越界被拦下 ✅
复验 lint exit=0   ← 删除临时文件后恢复全绿 ✅
```

→ **结论：边界规则真生效**（不是"配了不跑"）；临时文件已删除，工作区无残留（负向自检铁律：故意越界一次 → 必须报错 → **立即回滚**）。
