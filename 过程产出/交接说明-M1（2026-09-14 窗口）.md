## 五、环境 / 操作踩坑（下个窗口别重踩）

1. **端口**：本窗口用 **后端 3000 / 前端 5173**（`npm run dev`）。⚠ **vite 只监听 `::1`（IPv6）**：用 `http://127.0.0.1:5173` 会 **HTTP 000**，必须用 `http://localhost:5173` 或 `http://[::1]:5173`。
2. **`gen:types` 依赖后端在线**：脚本写死 `http://localhost:3000/docs-json` → 先起后端再跑，否则生成的 `types.ts` 会缺接口。
3. **入参 DTO 必须带 `@ApiProperty`**：否则 OpenAPI 里该 DTO 会退化成**空对象**（实测 `LoginDto: Record<string, never>`），前端类型等于不可用 → 会被迫手写对接（违反 M0-57）。
4. **给 curl 送 JSON body 不要用 PowerShell 管道**；改用 `Invoke-RestMethod -Body '<json 串>'` 或文件送体。
5. **`mysql -e "…"` 里的内层双引号会被 PowerShell 吞掉**（实测 `LIKE "x%"` 变成 `LIKE x%` → 语法错）→ 把 SQL 写进 **ASCII 临时文件**再 `-e "source <path>"`；`source` **打不开中文路径**。
6. **`operation_log` 是分区表**（覆盖 `p202609~p202712` ＋ **`pmax(MAXVALUE)` 兜底**）：⚠ **更正上轮说法** —— **有 `pmax` ⇒ 不会插失败**；真实风险是 **2028-01 起新行全落单一 `pmax`、老分区无法 `DROP PARTITION` 清理** → 须**每月固定续期**（口径＋部署清单见《数据架构文档》§十二「分区滚动（运维）」）。
7. 真库 `updated_at` 是 `datetime NOT NULL` **且无默认值** → 裸 SQL 插入必须显式给值（Prisma 的 `@updatedAt` 只在 ORM 内生效）。
8. `employee_role.role_code` / `permission_matrix.role_code` 是**外键指向 `role.code`** → 角色必须先插。
