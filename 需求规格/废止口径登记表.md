## 二、投稿规则（新拍板时怎么加）

1. **拍板推翻旧口径** → 立刻在 §一 **追加一行**（不删旧行）。
2. 同时**在正文里把旧段落改掉或标注**"已废止，见登记表 #N"——**本表不是免罪符**，正文该改还得改。
3. **同批执行机械扫描**：grep 旧词 / 旧版本号 / 旧文件名，确认无遗漏（口径见 README §八.4）。
4. 正文与登记表冲突时，**以登记表为准**。
