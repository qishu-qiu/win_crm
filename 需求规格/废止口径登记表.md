# 废止口径登记表（唯一登记处）

> **当前版本**：**V1.3**（2026-09-12，**22 条**）。版本沿革见 git。
> **读者**：AI 与开发者。
> **用法**：**读任何项目文档前，先读本表。** 表中「❌ 旧说法」一律**不得再作为实现依据**；一旦命中，按「✅ 现行口径」执行。
> **为什么需要它**：本项目文档读者是 AI —— 人靠语义能自动跳过过期段落，**AI 靠关键词命中，命中哪处就按哪处写代码**。本表把散落各处的"已废止说法"集中收口，防 AI 引用旧口径。
> **维护**：每次拍板推翻旧口径时**追加一行**（不删旧行，留痕）。由 AI 在同一次变更中同步。
> **与正文的关系**：正文若仍出现旧说法，**以本表为准**；本表只做"负面索引"，正面规则见五份现行文档（见 README §十 文档地图）。

## 二、投稿规则（新拍板时怎么加）

1. **拍板推翻旧口径** → 立刻在 §一 **追加一行**（不删旧行）。
2. 同时**在正文里把旧段落改掉或标注**"已废止，见登记表 #N"——**本表不是免罪符**，正文该改还得改。
3. **同批执行机械扫描**：grep 旧词 / 旧版本号 / 旧文件名，确认无遗漏（口径见 README §八.4）。
4. 正文与登记表冲突时，**以登记表为准**。

## 三、修改记录

> **★ 本档版本沿革不在文档内复述**（2026-09-12 决定 → 《废止口径登记表》#22）。
