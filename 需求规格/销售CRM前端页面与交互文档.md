## 一、文档体系与铁律

### 1.1 与四件套关系
- 本文件只定义「**长什么样、怎么交互**」。业务规则见 `→需求§X`，接口契约见 `→接口API§Y`，表结构见 `→架构表Z`。
- **同一事实只定义一次**（L1）：枚举/错误码/脱敏口径只写「见《接口 API 文档》§二」，不复制。

### 1.2 元铁律
- **L0 变更联动**：业务/接口一改，本文件同批改、同批升版。
- **信息架构不可动**（E3）：一级菜单顺序见 §四，换皮不许改。
- **★ 对齐铁律（2026-09-10 立）**：**需求/接口里定义的每一个动作、配置、复盘类功能，都必须在本文件有明确页面或章节落点**；新增功能不得只写进业务/接口而不落前端。

### 1.3 ★ 设计基准与「不自由发挥」（2026-09-11 立）
1. **一切数值走 §二 token**，页面/组件**禁止硬编码**颜色、间距、圆角、字号、阴影（C2/I1）。
2. 数值**不凭感觉**：颜色/控件高/圆角/字号/阴影一律取 Ant Design 5 官方默认值（见 §二 标注）。
3. **不引入未定义组件**：所需组件先在 §七 登记规格，再实现；不得随手造新视觉语言。
4. 有分歧时优先级：**Ant Design 官方约定 > 本文 §二 token > 个人偏好**。

## 二、设计系统 · Design Tokens（★ 单一事实源）

> 落地方式：全部编译为 CSS 变量（`--crm-*`）挂根节点；主题（light/dark × A/B/C）只换变量值，**不改组件**。下表数值基准＝Ant Design 5 默认 token。

### 2.1 Token 总原则
- **4 基数**：所有间距/尺寸尽量落在 4 的倍数网格。
- **一值一义**：同一语义只有一个 token，禁止同义多值。
- **语义优先**：组件引用语义 token（如 `--color-text-secondary`），不直接引用色值。

|---|---|---|

### 2.5 圆角
| Token | 值 | 用途 |
|---|---|---|
| `--radius-xs` | `2px` | 微元素（Segmented/箭头）|
| `--radius-sm` | `4px` | 小控件/标签（AntD borderRadiusSM）|
| `--radius-base` | `6px` | **控件基准**：按钮/输入框/下拉（AntD borderRadius）|
| `--radius-lg` | `8px` | 卡片/弹窗/抽屉（AntD borderRadiusLG）|
| `--radius-pill` | `999px` | 仅限头像/胶囊标签/客户芯片 |

### 2.6 阴影与层级（描边优先，阴影克制）
| Token | 值（AntD5） | 用途 |
|---|---|---|
| `--shadow-1` | `0 1px 2px 0 rgba(0,0,0,.05), 0 1px 6px -1px rgba(0,0,0,.03), 0 2px 4px 0 rgba(0,0,0,.03)` | 卡片（三级阴影）|
| `--shadow-2` | `0 6px 16px 0 rgba(0,0,0,.08), 0 3px 6px -4px rgba(0,0,0,.12), 0 9px 28px 8px rgba(0,0,0,.05)` | 下拉/悬浮卡/模态/抽屉 |
| `--shadow-3` | `0 12px 24px rgba(0,0,0,.10)` | 最高层（慎用） |

> **硬禁**：彩色阴影、发光阴影（glow）、用 `box-shadow` 做装饰。**卡片默认「1px 描边 + 极浅阴影」，不用重阴影堆叠**。

### 2.7 描边与分割线
- `--border-width: 1px`；控件用 `--color-border`，表格/区块分割用 `--color-border-secondary`。
- **分割线优先于阴影**：区块分离先用 1px `#f0f0f0` 线，不用阴影。

### 2.8 动效（极简，禁夸张）
| Token | 值 | 用途 |
|---|---|---|
| `--motion-duration-fast` | `0.1s` | 按压/微反馈 |
| `--motion-duration-base` | `0.2s` | 常规过渡（AntD motionDurationMid）|
| `--motion-duration-slow` | `0.3s` | 抽屉/模态进出 |
| `--motion-ease` | `cubic-bezier(0.645,0.045,0.355,1)` | 标准曲线 |

> **硬禁**：bounce/spring 夸张回弹、**无限循环动画（骨架屏除外）**、发光脉冲、位移放大、视差。动效只服务「层级出现/消失」，不做装饰。

### 2.9 图标
- 统一 **Feather 线性图标**（B1），stroke-width `1.5`，尺寸 `16 / 20 / 24`。
- **禁 emoji**（含状态、菜单、按钮、空状态插画）。

### 2.10 z-index 层级
| 层 | 值 |
|---|---|
| sticky 表头/工具栏 | `100` |
| 遮罩 mask | `999` |
| 抽屉/模态 | `1000` |
| 下拉/悬浮卡/Tooltip | `1050` |
| Message/Notification | `1010` |

### 2.11 控件尺寸
- 控件高 `--control-h: 32px` / SM `24` / LG `40`（AntD controlHeight）。
- 触控目标 ≥ `44×44`（HIG，移动端）。

## 三、设计总则 + 反 AI 味铁律

### 3.1 实体可点 + 一层抽屉 + 悬浮卡（A1~A7，[铁律]）
1. 公司/联系人/员工**任何位置**名称都可点（A1）；禁纯文本不可点（当前页即该实体详情页除外）。
2. 点公司 → **一层抽屉**，**永不叠第二层**（A2）。
3. 抽屉内点业务线 → 整页跳 `/relation/detail/:id` 并关抽屉；点联系人/销售 → **悬浮卡**（hover+click 钉住）（A3）。
4. **销售悬浮卡只放基础信息**，不放业绩/名下客户数（A4）。
5. 联系人悬浮卡含手机号脱敏+谈判特质+决策角色（A5）。
6. 跟单卡片统一显示「填单人+跟进联系人」且都可点（A6）。
7. 移动端悬浮卡 → 底部轻面板 `.sheet`，不叠抽屉（A7）。

### 3.2 视觉方向（B1~B8，[方向] 2026-09-09 推翻重做）
- **B1** emoji 全砍，统一 Feather 线性图标（语义不丢）。
- **B2** 大留白、浅色、一屏一主次。
- **B3** 主色只给可点按钮/链接/选中。
- **B4** 侧栏砍到销售日常 6 项 + 管理收进「更多」。
- **B5** 红色只给逾期/风险。
- **B6** 工作台 = 今天动作唯一入口。
- **B7** 卡片堆叠收敛。
- **B8** 高端大气、简单舒适、降学习成本。

### 3.3 ★ 反 AI 味铁律（2026-09-11 立 · 12 条硬禁）
1. **禁渐变**（背景/按钮/卡片/图表色块一律纯色）。
2. **禁玻璃拟态**（backdrop-filter / 半透明毛玻璃一律不用）。
3. **禁 emoji**（全站，含空状态）。
4. **禁发光 / 霓虹 / 彩色阴影**。
5. **禁夸张动画**（回弹、脉冲、无限循环、位移放大）。
6. **禁所有卡片一样大、一样重**（KPI/内容/列表按重要性分级，见 §十一.2）。
7. **禁装饰性插图 / 大圆角气泡 / 悬浮漂浮元素**。
8. **禁只有展示没有交互**（每个数据块要么可点、要么可筛选、要么可下钻）。
9. **禁同屏超过 3 个语义色**（红/橙/蓝/绿按需，不铺满）。
10. **禁无意义留白与超大标题**（信息密度服务操作效率）。
11. **禁假数据撑页面**（空就显示空状态，不填占位）。
12. **禁自定义视觉语言**（一切回归 Ant Design 组件观感）。

### 3.4 中国视觉习惯（H1~H4，[铁律]）
- **H1** 涨红跌绿；**H2** `¥`+千分位+等宽数字；**H3** 中文文案真实感；**H4** 红优先给紧急/逾期、系统标签灰 ⚙。

### 3.5 工作台 = 今日动作入口（B6）
- 今日概览（逾期红/预约/周重点绿/已跟进）+ 动作条直通（写跟进主按钮 ＋ 外出登记）+ 今日安排时间轴（逾期置顶红+补单/改期直达）+ 本周重点卡片「去跟进」。

## 四、信息架构与菜单（E1~E3）

一级菜单顺序（**固定，不可改**）：
`数据看板 → 工作台 → 预约管理 → 业务关系 → 录入 → 高级搜索 → 客户管理(系统公海/部门公海) → 客户档案(公司档案/联系人档案) → 合同管理 → 工单管理 → 交付管理(客户台账) → 审批中心 → 报表分析 → 组织架构(员工/部门/产品线/角色/权限) → 系统设置(公海规则/部门规则/工作流阶段/节奏规则/数据字典)`

- **目标与进度**：`→需求§7.11`，**经理/老板可见**，入口挂在「数据看板 / 报表分析」内，个人路由 `/target`。
- **消息中心**：不做一级菜单，走**顶部铃铛**（未读角标）→ `/notifications`。
- **个人中心 / 外观设置**：顶部头像菜单 → `/me/appearance`。
- **先做 7 高频页**（工作台/看板/业务关系列表/详情/预约/录入/公海）跑通新风格再铺开（E2）。
- 侧栏子菜单可折叠、状态持久化（D1）；顶部快捷入口 ≤6 动作型（D2/D3）。

## 六、单页关键需求

> 标注：`A~I`=历史清单编号；`→需求§`=业务规则；`→接口API§`=接口。

## 七、组件规格（★ 真实业务组件，全部走 §二 token）

### 7.1 表格 Table
- 结构：表头（高 47，`--color-bg-container`，字重 600，字号 14）+ 数据行（高 54，字号 14）+ 底部工具栏。
- 行分隔用 **1px `--color-border-secondary`**，**不用斑马纹**（减少噪音）。
- 行 hover：`--color-bg-hover`（唯一背景变化）；选中行：`--color-primary-bg`。
- 列对齐：文本左对齐、**数字右对齐＋等宽数字**、状态/操作居中。
- 列宽：关键列定宽（公司名/金额/时间），弹性列自适应；**表头可固定**（长表）。
- 排序/筛选：表头图标 `--color-text-tertiary`，激活态 `--color-primary`。
- 行操作：右侧固定，默认次要按钮，**主操作只留一个**；超 3 个收进「更多」。
- 空表：显示 §八.1 空状态（不显示空表格骨架）。
- 加载：表内 loading 遮罩 或 骨架行（§八.2）。
- 分页：见 7.3。

### 7.2 筛选 / 查询栏 FilterBar
- 布局：单行 inline（label 前置）或折叠面板；标签与控件间距 `--space-xs`。
- 高频筛选项 **≤5**，其余收「高级筛选」（展开不跳页）。
- 控件高统一 `32px`；输入/下拉宽度按语义（关键词 240、状态 120、时间 240）。
- 「查询」为主按钮、「重置」为 default；**筛选变化不自动清空已选**。
- 已选条件以可删除 Tag 回显（高 22、圆角 4、字号 12）。
- **筛选状态写入 URL query**（可分享/刷新不丢）。

### 7.3 分页 Pagination
- 位置：表格右下；左侧显示「共 N 条」。
- 页码 + 每页条数（20/50/100）+ 快速跳页。
- **列表类一律分页，不用无限滚动**（便于定位与回退）。

### 7.4 状态与标签 Tag / Status
- Tag：高 22、圆角 `--radius-sm`(4)、字号 12、内边距 4/8；纯色浅底 + 深字（同色系）。
- 状态统一用「**圆点 + 文字**」（色盲友好），必要时叠加图标。
- 业务档位色严格取 §二 业务色（紧迫档/等级/产品线）；系统自动项加灰色 `⚙`。
- **不堆 emoji、不用纯色块铺满格子**。

### 7.5 按钮 Button
- 类型：`primary`（主色实心，**同屏仅一个**）/ `default`（白底描边）/ `text`（无边框，次级）/ `link`（文字链）/ `danger`（错误色）。
- 尺寸：高 32 / 24(SM) / 40(LG)；图标+文字间距 `--space-xs`(8)。
- **点击反馈**：active 用 `--color-primary-active` 或背景加深（**不做位移动效**）。
- 禁用：文字 `--color-text-disabled` + 灰底 + `cursor: not-allowed`。
- 加载：按钮内 spinner + 保持宽度；**提交类按钮防重复点击**（§九.4）。
- 底部操作区：右对齐，主按钮最右。

### 7.6 表单与录入 Form
- 标签：顶部对齐（长表单）或左对齐固定宽（`120px`）；必填加红色 `*`。
- 控件高 32；多列用 24 栅格，`gutter: [16,0]`。
- 校验：blur 即时 + 提交汇总；错误文案红色 12px 置于控件下；helper 文案灰色 12px。
- 错误提示定位到字段并自动滚动到首个错误。
- 步进/分步表单用 Steps（录入页 3 步）。

### 7.7 抽屉 / 弹窗 / 悬浮卡
- **抽屉 Drawer**：仅一层（A2）；宽 `480`（小）/`640`（中）；标题栏高 56，底部操作区固定；进出 0.3s。
- **模态 Modal**：宽 `520`（确认）/`720`（表单）；标题 16/600；遮罩 `--color-bg-mask`；**禁玻璃拟态**。
- **悬浮卡 PopCard**：hover + click 钉住；宽 ≤320；`--shadow-2` + `--radius-lg`(8) + padding 16；移动端 → 底部轻面板 `.sheet`。
- 三者均用 **纯色底 + 描边/阴影**，无透明模糊。

### 7.8 时间轴 Timeline
- 节点 8px 圆点；连接线 1px `--color-border-secondary`；时间文字 12px `--color-text-tertiary`。
- **主线/树杈双色**（owner 主线 / 他人树杈），带图例；逾期段用红色分隔线标注。
- 每条含「填单人 + 跟进联系人」（可点）。

## 八、状态设计（★ 空 / 加载 / 错误 三态必须完整）

### 8.1 空状态 Empty
- 结构：**线性图标（非 emoji）+ 一句说明 + 一个主行动按钮**。
- 三类文案区分：**无数据**（「还没有业务关系，去录入」）/ **无搜索结果**（「没有符合条件的客户，试试放宽筛选」）/ **无权限**（「此处数据不在你的可见范围」）。
- 表格空、列表空、看板空各自适配，**不留大白块**。

### 8.2 加载状态 Loading
- 首屏用 **骨架屏 Skeleton**（贴合真实布局），**不用全屏 spinner**。
- 局部（按钮/表格）用控件内 loading；表格用表内遮罩。
- **>300ms 才显示 loading**（防闪烁）；<300ms 直接出数据。
- 骨架屏用浅灰块，**不做 shimmer 以外的效果**（§二.8）。

### 8.3 错误状态 Error
- 接口失败 → **错误态块**（图标 + 说明 + 「重试」按钮），可局部替换失败区块。
- 表单错误 → 字段红提示 + 汇总；提交失败 → `Message.error` 友好文案（映射 `→接口API§2.4` 错误码）。
- 网络断开 → 顶部常驻提示条；恢复后自动重试。

### 8.4 无权限 / 边界
- 403：页面/区块显示「无权限」占位（不报错、不空白）；越权数据**列表不返回、搜索搜不到**（`→接口API§2.2`）。
- 长文本溢出：单行省略 + Tooltip；数字超长：等宽缩略 + Tooltip。

## 九、交互规范（★）

### 9.1 hover（只做轻微背景变化）
- 表格行/列表项 hover：`--color-bg-hover`（`rgba(0,0,0,.04)`）。
- 文字按钮 hover：背景 `rgba(0,0,0,.06)`；链接 hover：`--color-primary-hover`。
- **硬禁**：hover 放大、位移、发光、阴影增强、渐变、颜色跳变。

### 9.2 点击反馈
- 所有可点元素有 active 态（背景加深/主色 `--color-primary-active`）。
- 行点击：整行可点（进详情）时行 hover 光标变手型；行内操作阻止冒泡。
- 异步操作点击后立即进入 loading（防重复点击）。

### 9.3 校验与提示
- 即时校验（blur）+ 提交校验；错误消息**指明原因与修正方式**。
- 危险操作（删除/判死）二次确认，确认按钮用 danger。

### 9.4 防抖 / 幂等
- 搜索输入 **300ms 防抖**；提交类请求带幂等键（`→接口API§2.5`）。
- 按钮 loading 期间禁用。

### 9.5 键盘与无障碍
- 焦点环：3px `--color-primary`（AntD `lineWidthFocus`）；Tab 顺序符合视觉流。
- `Esc` 关闭弹层；`Enter` 提交（表单）；下拉支持方向键。
- 对比度 ≥ 4.5:1；**不单靠颜色表意**；图标按钮带 `aria-label`。

## 十一、信息层级与密度（★ 主次分明、减少噪音、提高效率）

### 11.1 视觉层级四原则
1. **一屏一主**：每屏一个主任务、一个主按钮。
2. **三重区分**：字号 + 字重 + 色彩共同表达层级，不靠单一维度。
3. **同级一致**：同层级元素的间距、字号、颜色完全一致。
4. **次要降级**：辅助信息用 `--color-text-tertiary` 或 12px，不抢视线。

### 11.2 卡片不统一（禁所有卡片一样大一样重）
| 卡片类型 | 尺寸/内边距 | 重量 |
|---|---|---|
| KPI 卡 | 小、数字 30px/600 | 最轻（描边，无阴影）|
| 内容卡（区块）| 中、padding 24 | 中（描边 + `--shadow-1`）|
| 列表区/表格卡 | 大、占主区 | 主（无阴影，靠分割线）|

- **按重要性给不同内边距与视觉重量**；同一页避免 ≥4 个同等重量卡片并列。

### 11.3 降低噪音
- 低频操作收「更多」；同屏语义色 ≤3；边框优先于阴影；去掉装饰性元素。
- 数字对齐用等宽；状态用圆点+文字；时间统一 `YYYY-MM-DD HH:mm`。

## 十二、视觉 / 换肤规范（C1~C4）

## 十五、验收标准

**对齐 / 功能**
- 风格统一：全站走 §二 token，无 emoji、无旧深蓝侧栏味（B1/B4）。
- 实体可点：列表/卡片/跟单/审批/报表中无任何不可点公司名/人名（A1）。
- 抽屉只一层、悬浮卡不叠（A2/A3/A7）；销售悬浮卡无业绩/客户数（A4）。
- 跟单卡显示填单人+联系人且可点（A6）。
- 脱敏三处正确：跨线金额 `***`、非归属手机 `****后4`、公海未领不显全文（G4/G5）。
- 涨红跌绿、¥千分位+等宽数字（H1/H2）。
- 移动端仅工作台、底部 Tab、轻面板（F1~F3）。
- 换肤 light/dark×A/B/C 生效、个人外观持久化（C1~C4）。
- **无功能悬空**：判死/流失/复盘、目标、消息中心、节奏规则、外出登记、公海经理决策，六项缺一不可验收（§一.1.2 对齐铁律）。
- 紧迫档可设可筛；挂满 2 周强制二选一；等级（系统自动⚙）≠ 价值（手动软档）分开渲染、报表标「条/家」。
- 低摩擦录入：写跟单 ≤10 秒（一句话 + 承诺三快选）；快速标记可批量且不重置掉海倒计时。

**视觉 / 设计系统（★ V1.2 新增）**
- **token 统一**：颜色/间距/圆角/字号/阴影**零硬编码**，全部走 CSS 变量（抽查 0 例外）。
- **反 AI 味 12 条**（§三.3）全过：无渐变、无玻璃拟态、无 emoji、无发光、无夸张动画。
- **卡片分级**：KPI/内容/列表卡尺寸重量不同（§十一.2），无「千篇一律卡」。
- **真实组件**：表格/筛选/分页/状态/空状态均为真实业务组件（§七），非静态展示。
- **三态完整**：每个数据区都有 空/加载/错误 三态（§八）。
- **hover/点击**：hover 仅轻微背景变化；按钮有明确 active 反馈（§九.1/9.2）。
- **响应式**：桌面优先、≥1280 完整、移动端可用（§十）。
- **层级清晰**：一屏一主、主次分明、同屏语义色 ≤3（§十一）。
- 改版冒烟 0 错（I4）。
